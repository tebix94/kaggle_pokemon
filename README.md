## Run instructions

### 1. UV installation

Windows (Powershell)
```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```
Linux (Bash)
```
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Synchronize dependencies
Run the following command:
```
uv sync
```
That is it, environment is set and depedencies are created.

## 3. Run the project
1. Open the main.ipynb file with your favorite code editor
2. Select the uv environment kernel which is python-3.14.2
3. Run all the cells
